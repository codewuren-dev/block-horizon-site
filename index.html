方块视界Block Horizon

免费开源的 Minecraft Java 版启动器——实例隔离、整合包一键安装、微软正版登录、国内镜像加速，装完即玩。

当前公开版本 v0.14.35 · Windows 7 及以上（x64 / arm64）

它擅长什么

每一个能力都有自动化探针守着——「测过的就是用户点的」。

实例隔离

每个实例独立的 mods / saves / 配置，多整合包互不干扰；也支持隔离共享的轻量模式。

整合包一键安装

支持 .mrpack 与普通 zip 增量安装，装完自动过完整性校验，坏档不交付。

国内镜像加速

BMCLAPI 全量镜像（版本 / 库 / 客户端 / 资源），失败自动回落官方源，下载可随时取消。

崩溃取证

启动崩溃自动收集报告并给出人话结论，日志流触发、只认本次启动的报告。

第三方 / 离线登录

authlib-injector 外置登录开箱即用，离线账号与官方离线规则完全一致。

开源与克制

MIT 协议、核心层零 UI 依赖；零代码复制 PCL / HMCL，功能边界写得清清楚楚。
